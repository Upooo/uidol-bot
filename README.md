# Uidol

**Secure Multi-Client Telegram Userbot** — v0.0.1

Goo-style flow, cleaner structure, encrypted sessions, inline UI.

## Setup

```bash
cp .env.example .env
pip install -r requirements.txt
bash start.sh
```

## Fitur

- Inline menu
- Deploy phone→OTP→2FA (verified users only)
- Session encrypted
- Multi userbot + `.ping`
- Owner panel: grant/revoke, git, restart
- Log group + blockquote styling
